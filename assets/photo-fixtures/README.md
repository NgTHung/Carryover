# Capture probe fixtures

These deterministic fixtures contain no personal data. The five PNGs are
generated by the photo fixture generator. The JPEG carries EXIF orientation 6,
and the HEIC is a small HEIF test image used to exercise the native decoder.

The probe uses these files only for storage and encoding checks. It does not
represent camera permission or camera acquisition behavior.

The JPEG and HEIC files are the small test images from kamadak-exif 0.6.1.
The JPEG's EXIF orientation tag is set to 6 for the orientation probe. They
